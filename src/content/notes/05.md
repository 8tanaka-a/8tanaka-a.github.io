`/grill-me` は Matt Pocock さんが公開しているカスタムスキルです。Claude Code に追加して使い始めました。設計や計画に対して Claude が1問ずつ質問してくれるもので、各問いには推奨回答も添えられています。それをベースに議論しながら、認識の曖昧さを整理していく形です。

使っているのは Issue を作る前や、そこから実装に入る前のタイミング。自分の指示が思いのほか曖昧だったと気づくことが多く、齟齬を潰してから進める習慣になってきました。

コードベースが関係する質問は、Claude がリポジトリを読んで答えてくれることもあります。「このプロジェクトの場合はこうなっている」という文脈が乗るので、的外れな方向に進みにくい気がしています。

頭は使いますが、曖昧なまま実装に入るよりずっと健全だと感じています。
