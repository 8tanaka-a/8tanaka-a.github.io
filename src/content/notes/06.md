エンジニア仲間のアウトプット会で Devin を紹介してもらって、依存まわりの自動化に興味を持ちました。そういえば自分のサイトは、依存の更新を何も自動化していませんでした。

Devin でいいなと思ったのが、ユースケースのギャラリーです。具体例を眺めていると「ここは自分もやってみよう」と、自分の作業に引き寄せて考えられる気がします。

ただ Devin は有料なので、まずは自分の小さなリポジトリで Dependabot を試すことにしました。public リポジトリなら無料で、脆弱性を見つけて更新の PR を上げてくれます。

目指すのは、スキャンから修正、PR 作成までを自動で回して、マージだけ自分で判断する形です。追いつかない部分は Claude Code の GitHub Action でも補えないか、検討中です。
