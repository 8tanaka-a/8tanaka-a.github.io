モニタ1枚で、Ghostty のスペースをプロジェクトごとに切り替えながら並行開発をしています。複数の Claude Code が同時に動くと、全体の状態が把握しづらく感じていました。

そこでターミナルダッシュボードを作りました。Claude Code の hook を使って状態を JSON に書き出し、Rich の Live で 100ms ごとに描画します。リポジトリと worktree を一覧して、OFFLINE / WAITING / RUNNING / DONE をひと目で確認できます。

リポジトリ単位で登録すると worktree が自動で集約されます。別のスペースで動いている Claude の状態がスペースを離れずわかるのが、思ったより快適でした。

作る際に Opus で設計・Sonnet で実装という分担も体験できて、それも含めて楽しい開発でした。いまのところ毎日使っていて、手放せないオトモになっています。
